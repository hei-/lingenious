# 0001. The LLM designs, the geometry kernel judges

- Status: Accepted
- Date: 2026-10

## Context

An LLM can write plausible CadQuery code, but it cannot reliably tell whether the resulting solid is valid,
matches the requested dimensions or can be machined. Asking an LLM to grade its own output makes results
non-reproducible, hard to evaluate and impossible to ablate. OpenCASCADE exposes the exact B-Rep (faces,
edges, cylinders, volumes, bounding boxes), so these questions can be answered by code.

## Decision

Split the work strictly:

- **LLM** (`core/agent`, `core/llm.py`): parse the requirement into a `PartSpec`, write the script, repair it
  given a list of violations, apply follow-up changes.
- **Deterministic Python**: sandboxed execution (`core/sandbox`), all pass/fail judgement (`core/checks`:
  L1 validity, L2 requirement match, L3 DFM), rendering, drawings, export and retry control.

Every check returns `Issue` objects with a numeric `message`, `measured` / `required` values and a `hint`
generated by the rule code, not by the LLM. Only `error` severity blocks; `warning` is reported. The
loop stops on success, after `agent.max_rounds`, or when the script and failing rules repeat.

## Consequences

- The same geometry always gets the same verdict; checks are unit-tested with positive and negative cases
  and run without an API key.
- Feedback to the LLM is concrete ("hole centre 3.0 mm from edge, required >= 9.9 mm") instead of vague.
- Evaluation can grade outputs with the same checks against independent ground truth
  ([ADR 0005](0005-ground-truth-from-reference-solids.md)).
- The checks are only as good as their geometry heuristics and thresholds: wall thickness is an
  approximation over near-parallel planes, and DFM thresholds are rules of thumb pending review
  ([dfm-rules.md](../dfm-rules.md)). Passing means "obeys these rules", not "is manufacturable".
- One exception is unavoidable: L2 assertions come from the LLM's reading of the requirement, see
  [ADR 0003](0003-disputable-l2-assertions.md).
