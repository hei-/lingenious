# DFM 规则复核清单(给工艺人员)

说明:下表中的阈值是开发时设定的通用经验值,**没有经过工艺人员复核,也没有对应任何标准或手册出处**。请按贵车间的实际设备、刀具、材料判断是否合适,并在最右列填写结论。所有阈值都在 `config.yaml` 的 `dfm` 段,可以直接改。

默认前提:铝合金 6061,数控铣削。钢件有一组占位覆盖值(同样未复核)。

| 规则 id | 检查什么 | 当前默认阈值 | 为什么可能不适合你们 | 请确认 | 你的答复 / 签字 / 日期 |
|---|---|---|---|---|---|
| `min_wall_thickness` | 两个相对近平行平面之间的壁厚 | 小于 1.5mm 报错,小于 2.0mm 警告;钢件 2.0mm | 最小壁厚取决于壁高、材料、夹持与刀具,同样 1.5mm 在低矮和高大的壁上难度不同 | 铝/钢/其他材料各自的可加工最小壁厚?是否要与壁高挂钩? | |
| `hole_edge_distance` | 孔壁到最近外边缘的距离 | 不小于 1.5×孔径,且不要求超过 6mm | 取决于材料强度、孔是否承力、是否有倒角 | 倍数 1.5 与 6mm 上限是否合理? | |
| `internal_corner_radius` | 内凹角必须有圆角 | 半径小于 0.5mm 报错;小于 3mm 警告;无圆角报错 | 最小圆角取决于你们现有最小铣刀直径与悬长;3mm 只是"方便用大刀"的建议值 | 最小可用刀具半径?推荐半径取多少? | |
| `hole_spacing` | 相邻平行孔之间的孔间壁 | 不小于较小孔径(1×) | 与材料、孔深有关,深孔更易偏斜 | 倍数是否合适? | |
| `hole_depth_ratio` | 盲孔深/径比;通孔按穿过的板厚/径比 | 盲孔大于 6 警告,大于 10 报错;通孔大于 6 仅警告;钢件 5 / 8 | 是否有深孔钻、枪钻、啄钻、冷却条件;不同孔径与材料差别很大;孔深不含锥底 | 常规钻头可达的深径比?超过多少必须换工艺?通孔是否也要限制? | |
| `deep_pocket` | 封闭型腔的深度/最小腔宽 | 大于 4 警告;钢件 3 | 取决于刀具悬长、刚性与是否允许长刃刀;圆形盲孔不算腔,归孔规则 | 深宽比上限?是否需要区分有无圆角? | |
| `thin_web_height` | 薄筋/薄壁的高度/厚度 | 大于 8 警告,只检查厚度不超过 5mm 的;钢件 6 | 取决于材料、是否有支撑、切削参数;程序无法区分"筋"和"悬臂薄法兰",两者都会提示 | 高厚比上限?"薄"的厚度界限 5mm 是否合适? | |
